Personal AI engineering lab for [Ajith Thaduri](https://www.ajiththaduri.site/).

## Layout

```
experiments/<exp-id>-<slug>/
```

## Experiments

| Path | Label |
| --- | --- |

## Rules

- One experiment per folder
- Pull requests stay open until Ajith approves merge
- Results must be labeled honestly (including SELF-EVALUATED / EXPLORATORY when applicable)
- Do not claim DUMA-Bench or multi-model independence without evidence
